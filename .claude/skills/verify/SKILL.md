# Verify TRI Momentum (race-day tools)

- **Launch:** `git worktree add --detach <dir> <sha>` for a pinned copy, then `python3 -m http.server <port> -d <dir>/public`. No env vars, nothing to install.
- **Seed:** smoke seeds its own storage. For old saves, copy `scripts/fixtures/save-before-four-step.json` (a made-up athlete), set `race.date` to a future day, and inject it into `localStorage['race-day-tools.v1']` with `addInitScript` guarded by `if(!getItem)`.
- **Widths:** 390, 360, 320. No `@media` breakpoint other than print.
- **Checks:** `npm test` ends `# fail 0`. `npm run smoke` ends `Smoke test passed.` with no `failed:` lines (`SHOTS=<dir>` saves screenshots). `require('playwright')` works from any directory. For print, dispatch `window.dispatchEvent(new Event('beforeprint'))`, then `emulateMedia({media:'print'})`, and read `#print-root`. Useful ids: gut field `#f-details-gut`, own sweat `#f-details-sweat`, rail `nav.rail`. Email block on step 4: `section.mail`, field `getByLabel('Email me this race card', {exact:true})`, result line `section.mail [role=status]`. Stub the send with `page.route('**/api/send', ...)`: a 503, `route.abort()` and `ctx.setOffline(true)` give the failure cases, and no stub gives a 404. The PDF the browser sent is `Buffer.from(JSON.parse(postData).pdf,'base64')`; `pdftotext` reads it. The send function runs in plain Node: `await import('functions/api/send.js')`, then call `handler(new Request(...,{headers:{Origin,'Content-Type':'application/json'}}), env, {fetch, log, now})` with a stub fetch and the console captured. The block is hidden on `*.github.io`, so run browser checks on localhost.
- **Traps:** the router uses hashes, the "Next: ..." controls are buttons, so use `getByRole('button')` or `getByText`; `getByRole('link')` fails because they are not links. `getByLabel(/sweat rate/i)` matches the pill group first. The print card is built only on `beforeprint`. Remove worktrees with `git worktree remove --force`. When you break a rule in a scratch copy to prove a test fails, aim at the `<meta>` line: the first `connect-src 'self'` match in a file is a comment. An email input strips newlines, so a newline test shows a joined string. Read the button after a fast stub reply and you miss "Sending..."; delay the stub, as smoke does. Editing storage does not make a plan stale. Never set `SHOTS` to a path inside the repo. To test the send function's PDF check, hide names that are on neither list (for example `/Bogus`), so the allowlist and not the deny list does the refusing, and build a control of the same skeleton that is accepted. Each post needs a fresh email and IP or the limiter returns 429. The Olympic distance key is `standard`. A mutation that is too broad breaks every real card and proves nothing: narrow it. Plain `node` from a scratch directory; this Node has no `-I` option.
